Hanuman Mandir Management System

A modern React-based web application for managing Hanuman Mandir areas, dashboards, and temple-related information.

    🚀 Features
    📊 Dashboard Page
    🏛 Area Management
    📱 Responsive Design
    ⚡ Fast Performance using Vite
    🎨 Tailwind CSS UI
    🔀 React Router Navigation
    
🛠 Tech Stack
    React JS
    Vite
    Tailwind CSS
    React Router DOM
    JavaScript
